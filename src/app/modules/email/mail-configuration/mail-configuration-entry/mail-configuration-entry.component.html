How Mail Trigger Works
Company Scope
This configuration is company-specific. A company must be selected during configuration creation. The configuration will be applicable only to the selected company, and any modifications made during editing will affect only that company. It will not be applied to other companies.
Trigger Type
Auto means this rule is checked during Save (Create/Update). Manual means this rule is checked only when user clicks Send Mail.
Auto / Popup Mode
After rule match: Auto sends directly. Popup opens email compose window so user can review and send.
Action Filter
Create runs when new record is saved. Update runs when existing record is saved. If both selected, both save operations can trigger this rule.
Recipient Resolution
System resolves To/CC using template placeholders and runtime context. In Lead mode, lead email is used. In Customer mode, customer/config-based addresses are used.
Quick Flow Summary
Save -> checks Auto rules -> matches Company + Menu + Action + Status -> resolves recipients -> sends/popup by Auto/Popup.
Send Mail button -> checks Manual rules only.
